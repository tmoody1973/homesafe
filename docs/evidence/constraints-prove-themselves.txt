Captured 2026-08-13 against cluster drying-gerbil (CockroachDB v26.2.5)

These are not tests that assert. These are the database refusing to store
data that would let HomeSafe mislead someone.

--- 1. A public record cannot exist without saying what it does NOT prove ---
Attempted: INSERT INTO public_event (...) with no caveat

  ERROR:  null value in column "caveat" violates not-null constraint

Why this matters: "a permit is not proof that a repair happened" is the
single most important caveat in the product. It is enforced by the schema,
not by anyone remembering to add it.

--- 2. An unknown issue category is rejected at write time ---

  ERROR:  failed to satisfy CHECK constraint (event_category IN

   'permit':::STRING, 'utilities':::STRING, 'sanitation':::STRING,
   'other':::STRING))

Why this matters: a typo in an ingestion adapter fails immediately rather
than producing a category that renders as a blank badge in the UI.

--- 4. The vector width is enforced, not decorative ---
CockroachDB v26.2.5 accepted VECTOR(1024) as written. Column type
reports as `vector`. Width is checked on every insert:

  1023 elements -> REJECTED: expected 1024 dimensions, not 1023
  1024 elements -> SUCCEEDED
  1025 elements -> REJECTED: expected 1024 dimensions, not 1025

Why this matters: 1024 is Amazon Titan v2's actual output width, measured
by calling the model. A silently-wrong width would produce garbage
similarity scores in plan 3 rather than an error — the worst kind of bug
for a feature whose entire job is being trustworthy.

--- 5. Unknown memory types are rejected at write time ---
  ERROR: failed to satisfy CHECK constraint (memory_type IN
  ('resident_observation', 'agent_summary', 'policy_guidance',
   'issue_definition'))

--- 6. Deleting a case removes its private data ---
  before delete -> observations: 1 | memory: 1
  after delete  -> observations: 0 | memory: 0

Why this matters: a deleted case cannot leave orphaned private resident
notes or embeddings behind. Enforced by ON DELETE CASCADE, not by
application cleanup code that might be skipped.
